# Git Commit Rules

- 모든 Git 커밋 메시지는 반드시 한국어로 작성한다.
- 사용자가 별도로 영어 커밋 메시지를 요청하지 않는 한 영어 문장을 사용하지 않는다.
- Conventional Commits 형식을 준수한다.
- `type`과 선택적인 `scope`는 영어로 작성한다.
- `subject`와 `body`는 한국어로 작성한다.
- `subject` 끝에 마침표를 사용하지 않는다.

## 허용 예시

- `feat: 사용자 관리 기능 추가`
- `fix(auth): 로그인 세션 만료 오류 수정`
- `refactor(api): 사용자 API 구조 개선`
- `docs: 배포 문서 업데이트`
- `chore: 의존성 버전 업데이트`
